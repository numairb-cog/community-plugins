Initial release of AIMD plugin for Backstage community plugins.

**Features:**

- New AIMD catalog entity kind for managing markdown documentation
- Frontend plugin with EntityAimdContent component for rendering markdown
- Backend module with entity validation and processing
- Support for consumesAimd/aimdConsumedBy relations
- Comprehensive unit tests for validators, processors, and components
